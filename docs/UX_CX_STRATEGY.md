# PIXEL MART — UX / CX Strategy

## 1. 문서 목적

이 문서는 PIXEL MART의 사용자경험(UX)과 고객경험(CX) 방향을 정의합니다.

PIXEL MART는 단순히 상품을 진열하고 판매하는 쇼핑몰이 아니라,
사용자가 자신의 취향을 발견하고, 구매 실패를 줄이며,
같은 취향의 사람들과 관계를 형성하도록 돕는 서비스를 목표로 합니다.

---

## 2. 핵심 UX / CX 원칙

### 2.1 상품보다 취향에서 시작

일반 쇼핑몰은 상품명을 알고 있다는 전제에서 탐색을 시작하는 경우가 많습니다.

PIXEL MART는 사용자가 정확한 상품명을 모르더라도 다음과 같이 탐색할 수 있어야 합니다.

- 보라색 RPG 느낌
- 귀여운 키보드 꾸미기
- 레트로 데스크
- 오로치마루 굿즈
- Keychron K8에 맞는 키캡

### 의도

상품 중심 탐색이 아니라 사용자의 취향과 상황 중심으로 탐색 경험을 설계합니다.

### 기대효과

- 원하는 상품을 더 쉽게 발견
- 검색 실패 감소
- 탐색 시간 단축
- 상품 노출 기회 증가
- 개인화 추천 기반 확보

---

## 3. Search / Filter Strategy

검색과 필터는 PIXEL MART의 핵심 CX 기능으로 봅니다.

### 3.1 검색 대상

검색은 상품명뿐 아니라 다음 정보까지 포함하는 방향으로 설계합니다.

- 상품명
- 카테고리
- 캐릭터
- 작품
- 색상
- 분위기
- 게임 장르
- 기기 모델
- 호환 규격
- 지역
- 판매 / 교환 여부

예:

```text
"핑크 키캡"
"보라색 RPG 데스크"
"분당 나루토 굿즈"
"Keychron K8 호환 키캡"
"오로치마루 교환 가능"
```
# 4. Faceted Search

사용자가 여러 조건을 동시에 조합할 수 있도록 합니다.

| 구분 | 예시 |
| --- | --- |
| 상품 종류 | 키캡 / 장패드 / 무드등 / 키링 / 피규어 |
| 캐릭터 | 오로치마루 / 슬라임 / 고스트 등 |
| 작품 | 나루토 / 레트로게임 등 |
| 색상 | Pink / Purple / Green / Black |
| 분위기 | Cute / Retro / Neon / Dark |
| 가격 | 1만원 이하 / 1~3만원 / 3만원 이상 |
| 기기 모델 | Keychron K8 등 |
| 호환성 | 내 기기 호환 상품만 |
| 지역 | 판교 / 분당 / 강남 등 |
| 거래 방식 | 판매 / 교환 |
| 정렬 | 인기순 / 신상품 / 낮은 가격 / 높은 가격 |

### 의도
고객이 정확한 상품명을 몰라도
자신이 원하는 조건을 조합해 상품을 찾을 수 있도록 합니다.

### 기대효과
- 탐색 효율 향상
- 검색 결과 품질 개선
- 구매 가능성이 높은 상품으로 빠른 이동
- 취향 데이터 축적
