# PIXEL MART — Deskterior Tournament 운영정책

## 1. 문서 목적

본 문서는 PIXEL MART의 핵심 CX 기능인 **Deskterior Tournament**의 운영 기준과 사용자 참여 규칙을 정의합니다.

Deskterior Tournament는 모든 사용자가 동일한 기본 데스크에서 PIXEL MART에서 판매하는 상품을 조합하여 자신만의 데스크를 만들고, 다른 사용자들의 투표를 통해 순위를 결정하는 참여형 콘텐츠입니다.

이 기능은 단순히 상품을 많이 배치하는 사용자가 유리한 구조가 아니라, 제한된 조건 안에서 자신의 취향과 배치 감각을 표현하는 것을 목표로 합니다.

---

## 2. 기획 목적

일반적인 쇼핑몰은 다음과 같은 흐름으로 끝납니다.

상품 탐색  
→ 구매  
→ 배송  
→ 서비스 이용 종료

PIXEL MART는 구매 이후의 경험을 다시 서비스 안으로 연결합니다.

상품 탐색  
→ 구매  
→ 데스크 꾸미기  
→ Deskterior 등록  
→ 다른 사용자 투표  
→ Tournament  
→ 다른 데스크 구경  
→ 새로운 상품 발견  
→ 재방문

이를 통해 고객이 구매한 상품의 실제 사용 모습이 다시 새로운 콘텐츠가 되는 구조를 만듭니다.

---

## 3. 기본 데스크 정책

모든 사용자는 동일한 조건에서 시작합니다.

| 항목 | 운영 기준 |
| --- | --- |
| 기본 데스크 | 동일한 흰색 Pixel Desk |
| 데스크 크기 | 모든 사용자 동일 |
| 배경 | 동일한 기본 배경 |
| 사용 가능 상품 | PIXEL MART 등록 상품 |
| 외부 이미지 | 사용 불가 |
| 사용자 임의 업로드 | 이번 프로젝트에서는 제외 |
| 제출 작품 | 라운드별 1인 1개 |

### 기획 의도

데스크 자체의 차이가 아니라 사용자가 선택한 상품과 조합 능력으로 경쟁하도록 합니다.

---

## 4. 상품 사용 정책

### 4.1 상품 개수 제한

한 데스크에 배치할 수 있는 상품 수를 제한합니다.

- 최소 3개
- 최대 7개

### 제한 이유

상품을 많이 붙일수록 화려해지는 구조가 되면 취향과 디자인보다 상품 수가 승패를 결정할 수 있습니다.

따라서 모든 사용자가 비슷한 조건에서 어떤 상품을 선택할지 고민하도록 합니다.

---

### 4.2 동일 상품 중복 제한

동일한 상품은 하나의 데스크에 기본적으로 1개만 배치할 수 있습니다.

예:

슬라임 무드등 × 5 → 불가  
슬라임 무드등 × 1 → 가능

### 기획 의도

특정 상품을 반복해서 배치해 화면을 채우는 행위를 방지합니다.

---

## 5. Decoration Point 정책

상품 개수 제한과 함께 **Decoration Point(DP)** 제도를 적용합니다.

모든 사용자는 동일하게 **100 DP**를 받습니다.

상품마다 필요한 DP가 다릅니다.

| 상품 유형 | 예시 DP |
| --- | ---: |
| 키캡 | 10 |
| 키링 | 10 |
| 소형 피규어 | 15 |
| 무드등 | 20 |
| 장패드 | 25 |
| 대형 장식 | 30 |

예:

장패드 25  
+ 무드등 20  
+ 키캡 10  
+ 피규어 15  
+ 키링 10  

= 80 DP

100 DP를 초과하면 출품할 수 없습니다.

### 기획 의도

모든 상품을 다 사용하는 것이 아니라,

**“무엇을 넣고 무엇을 포기할 것인가?”**

를 고민하도록 합니다.

게임에서 제한된 장비 슬롯에 아이템을 장착하는 경험과 유사하게 설계합니다.

---

## 6. 카테고리별 제한

특정 상품군만 반복해서 사용하는 것을 방지하기 위해 카테고리별 최대 배치 수를 설정합니다.

| 카테고리 | 최대 배치 |
| --- | ---: |
| 장패드 | 1 |
| 키보드 / 키캡 세트 | 1 |
| 무드등 | 2 |
| 피규어 | 2 |
| 키링 / 소형 굿즈 | 2 |
| 대형 장식 | 1 |

Tournament에 출품하려면 최소 2개 이상의 서로 다른 카테고리를 사용해야 합니다.

---

## 7. 상품 배치 정책

완전히 자유로운 Drag & Drop 방식보다 지정된 영역에 상품을 배치하는 **Snap Zone 방식**을 우선 적용합니다.

예:

LEFT AREA | CENTER AREA | RIGHT AREA

KEYBOARD AREA

FRONT AREA

상품 종류에 따라 배치할 수 있는 위치를 제한합니다.

예:

- 키캡 → Keyboard Area
- 장패드 → Desk Center
- 무드등 → Left / Right Area
- 피규어 → Left / Right / Front Area

### 기획 의도

다음 문제를 예방합니다.

- 상품끼리 겹치는 문제
- 상품이 화면 밖으로 나가는 문제
- 비정상적인 크기 조정
- PC와 모바일에서 위치가 달라지는 문제
- 개발 난이도 증가

---

## 8. 상품 크기 정책

상품별 기본 크기를 정의합니다.

| 상품 | 크기 |
| --- | --- |
| 키캡 | Fixed |
| 장패드 | Fixed |
| 키링 | Small |
| 피규어 | Medium |
| 무드등 | Large |

사용자가 상품 크기를 무제한으로 확대하거나 축소할 수 없도록 합니다.

### 기획 의도

실제 상품 비율을 유지하고 특정 상품을 크게 키워 투표에서 유리해지는 것을 방지합니다.

---

## 9. 출품 조건

Deskterior Tournament에 참가하려면 다음 조건을 만족해야 합니다.

| 조건 | 기준 |
| --- | --- |
| 사용 상품 | 최소 3개 |
| 최대 상품 | 7개 |
| DP | 100 이하 |
| 카테고리 | 최소 2종 이상 |
| 동일 상품 | 기본 1개 |
| 제출 | 라운드별 1인 1개 |
| 수정 | 투표 시작 전까지 가능 |

Tournament가 시작된 이후에는 출품 작품을 변경할 수 없습니다.

---

## 10. Tournament 운영방식

참가 인원이 많을 경우 처음부터 모든 참가자를 1:1 토너먼트로 진행하지 않습니다.

참가 인원에 따라 **예선 → 본선 Tournament** 구조를 사용합니다.

예:

100명 참가  
→ 예선 Gallery Vote  
→ 상위 32명 선정  
→ 32강  
→ 16강  
→ 8강  
→ 4강  
→ 결승  
→ PIXEL DESK CHAMPION

### 핵심 원칙

참가자가 많을수록 예선에서는 많은 작품을 빠르게 평가하고, 본선부터 1:1 대진 방식을 적용합니다.

이렇게 해야 참가자가 자신의 대결 순서를 오래 기다리는 병목을 줄일 수 있습니다.

---

## 11. 예선 — Gallery Vote

참가자가 일정 수 이상인 경우 예선에서는 여러 개의 데스크를 한 번에 보여줍니다.

예:

DESK 01 / DESK 02 / DESK 03

DESK 04 / DESK 05 / DESK 06

사용자는 마음에 드는 데스크를 제한된 개수만큼 선택합니다.

예:

**“가장 마음에 드는 데스크 3개를 선택해주세요.”**

예선 투표 결과 상위 참가자가 본선 Tournament에 진출합니다.

### 예시

100명 참가  
→ Gallery Vote  
→ 상위 32명 선발  
→ 32강 진출

### 기획 의도

참가자가 많을 때 100명의 참가자가 자신의 대결 순서를 기다리는 병목을 방지합니다.

또한 많은 작품을 짧은 시간 안에 사용자가 탐색할 수 있도록 합니다.

---

## 12. 본선 — 1:1 Tournament

예선을 통과한 참가자부터 1:1 Tournament 방식을 적용합니다.

예:

32강  
→ 16강  
→ 8강  
→ 4강  
→ 결승

본선 화면 예시:

DESK A

VS

DESK B

사용자는 자신의 취향에 더 가까운 하나의 데스크를 선택합니다.

---

## 13. 참가자 수에 따른 운영 기준

| 참가자 수 | 운영 방식 |
| --- | --- |
| 2~16명 | 바로 Tournament |
| 17~32명 | 32강 또는 간단한 예선 후 Tournament |
| 33~64명 | Gallery 예선 → 32강 |
| 65명 이상 | Gallery 예선 → 상위 32명 → Tournament |
| 100명 이상 | Gallery 예선 → 상위 32명 → Tournament |

실제 서비스에서는 참가 규모에 따라 예선 통과 인원을 탄력적으로 조정할 수 있습니다.

---

## 14. 투표 정책

공정성을 위해 다음 정책을 적용합니다.

- 자신의 작품에는 투표할 수 없음
- 같은 대결에 중복 투표 불가
- 참가자 이름은 투표 종료 전 숨김
- 상품 가격은 투표 화면에서 숨김
- 모든 참가자는 동일한 상품 사용 제한 적용
- 비정상 반복 투표는 집계에서 제외할 수 있음

### 참가자 이름을 숨기는 이유

사용자의 인지도나 친분이 아니라 실제 데스크의 취향과 디자인을 보고 투표하도록 하기 위함입니다.

---

## 15. 투표 기준

서비스가 취향 기반 플랫폼이므로 복잡한 점수표보다 직관적인 선택을 제공합니다.

사용자 안내 문구:

**“내 취향에 더 가까운 데스크를 선택해주세요.”**

내부적으로 고려하는 기준은 다음과 같습니다.

- 상품 간 조화
- 공간 활용
- 콘셉트 완성도
- 개성
- 취향 표현

---

## 16. 동점 처리

예선 또는 Tournament에서 동점이 발생할 경우 다음 순서로 처리합니다.

1. 추가 투표
2. 추가 투표가 어려운 경우 랜덤 타이브레이크

향후 실제 서비스에서는 누적 활동점수 등의 보조 기준을 사용할 수 있습니다.

---

## 17. BOSS CLEAR 연계

Tournament 결과는 PIXEL MART의 Gamification과 연결합니다.

예:

참가  
→ PIXEL CHALLENGER

8강  
→ DESK FIGHTER

결승 진출  
→ DESK MASTER

우승  
→ BOSS CLEAR!

우승자의 프로필에는 Trophy Badge를 제공합니다.

예:

🏆 BOSS CLEAR!  
2026 OCTOBER PIXEL DESK CHAMPION

### 기획 의도

사용자가 구매 내역뿐 아니라 PIXEL MART 안에서 자신의 활동과 성취를 기록하도록 합니다.

---

## 18. 상품 상세 및 구매 연결

다른 사용자의 Deskterior를 구경하다가 해당 데스크에 사용된 상품을 선택하면 상품 상세 페이지로 이동할 수 있습니다.

예:

이 데스크에 사용된 상품 5개

- Pixel Lamp
- Purple Keycap
- Dungeon Desk Mat
- Ghost Figure
- Pixel Keyring

상품 선택  
→ 상품 상세  
→ 장바구니  
→ 구매

### 기대효과

사용자의 콘텐츠가 새로운 상품 진열장 역할을 하게 됩니다.

---

## 19. PIXEL LOCAL 연계

Deskterior Tournament는 지역 기반 커뮤니티 PIXEL LOCAL과 연결할 수 있습니다.

예:

- 분당 PIXEL DESK CUP
- 판교 BEST DESK
- 강남 RETRO DESK WEEK

또한 상품 상세에서:

**“이 상품을 사용한 판교 Desk 12개”**

와 같이 지역 + 상품 + 사용자 콘텐츠를 연결할 수 있습니다.

---

예:

- desk_size
