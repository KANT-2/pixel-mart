# PIXEL MART 기획 메모 (A 담당 초안)

> 노션 "기획" 페이지에 그대로 붙여넣고 팀 회의에서 다듬어 주세요.

## 1. 콘셉트
- **쇼핑몰 이름**: PIXEL MART
- **한 줄 소개**: 게임을 좋아하는 사람을 위한 픽셀아트 데스크 소품 상점
- **카피**: "일상에 아이템을 장착하세요."
- **대상**: 게임을 좋아하는 20~30대, 책상을 꾸미고 싶은 사람(데스크테리어)
- **Use Case**: **디지털/IT 기기 샵** — 키캡, 장패드, 무드등 같은 게이밍 데스크 주변기기 중심으로 변형
  - ⚠️ 튜터님 확인 필요: "IT 기기 샵을 게이밍 데스크 소품으로 좁혀도 되는지"
- **디자인 톤**: 다크 아케이드 · 픽셀아트 · 네온 포인트 1색(연두)

## 2. 범위
| 구분 | 내용 |
| --- | --- |
| ✅ 필수 | 메인 · 상품 목록 · 상품 상세(동적 라우트), 헤더 · 푸터 · 상품 카드 컴포넌트, `<Link>` 이동, 없는 상품 ID 안내 |

| ❌ 하지 않음 | 로그인/회원가입, 결제, DB·서버 연동, 장바구니 서버 저장, 검색·필터·정렬 |

## 4. 화면별 필수 요소 (와이어프레임 그릴 때 체크리스트)

### 메인 `/`
- [ ] Header (로고 → `/`, 메뉴: 홈 · 전체 상품, 카트 아이콘)
- [ ] 히어로 배너: 카피 + "상품 둘러보기" 버튼 → `/products`
- [ ] 추천 상품 4개 (ProductCard 재사용) + "전체 보기" 링크
- [ ] Footer

### 상품 목록 `/products`
- [ ] 페이지 제목 + 총 상품 수 ("전체 8개")
- [ ] 상품 카드 그리드 (전체 `.map()`)
- [ ] 카드: 이미지(정사각형) · NEW 뱃지(isNew) · 카테고리 · 이름 · 가격 → 클릭 시 상세

### 상품 상세 `/products/[id]`
- [ ] 이미지(왼쪽) / 정보(오른쪽): 카테고리 · 이름 · 가격 · 설명
- [ ] "장바구니 담기" 버튼 (선택 과제 B와 연결)
- [ ] "목록으로" 링크
- [ ] **없는 ID** (`/products/999`): "상품을 찾을 수 없습니다" + 목록으로 가기

## 5. 사용자 흐름
```
메인 ──(상품 둘러보기 / 전체 보기)──▶ 목록 ──(카드 클릭)──▶ 상세
  ▲                                   ▲                     │
  └──────────(헤더 로고)───────────────┴─────(목록으로)───────┘
```
