# PIXEL MART — Product Strategy

## 1. 서비스 정의

PIXEL MART는 레트로 게임·캐릭터·게이밍 데스크 굿즈를 판매하는
**취향 기반 커뮤니티 커머스**를 지향합니다.

단순히 상품을 검색하고 구매하는 쇼핑몰이 아니라,

취향 발견
→ 상품 탐색
→ 실제 사용 모습 확인
→ 구매
→ 데스크 인증
→ 지역의 같은 취향 사용자 발견
→ 거래·교환·커뮤니티
→ 재방문

으로 이어지는 경험을 만드는 것이 목표입니다.

---

## 2. 해결하려는 문제

### 문제 1. 상품은 많지만 내 취향에 맞는 상품을 찾기 어렵다

일반 쇼핑몰은 상품명과 카테고리 중심으로 탐색합니다.

PIXEL MART는 다음 정보를 활용해 취향 중심 탐색을 지원하는 방향으로 설계합니다.

- 캐릭터
- 작품
- 색상
- 분위기
- 게임 장르
- 상품 종류
- 가격
- 기기 모델
- 호환 여부
- 지역

### 문제 2. 구매 전 실제 사용 모습을 확인하기 어렵다

특히 키캡처럼 기기 규격의 영향을 받는 상품은
구매 이후 호환되지 않는 문제가 발생할 수 있습니다.

이를 호환성 확인과 미리착샷으로 구매 전에 해결합니다.

### 문제 3. 구매 이후 고객과 서비스의 관계가 끊어진다

일반 쇼핑몰은 구매가 완료되면 사용자 경험도 종료되는 경우가 많습니다.

PIXEL MART는 데스크테리어, 토너먼트, 지역 커뮤니티,
거래·교환 기능을 통해 구매 이후에도 다시 방문할 이유를 만듭니다.

# 3. Core Feature 01 — Deskterior Tournament

## 기능 정의

사용자가 PIXEL MART 상품 또는 자신이 보유한 굿즈로 꾸민 데스크를 공유하고,
다른 사용자들이 투표하여 토너먼트 방식으로 경쟁하는 기능입니다.

사용자 데스크 등록
→ 사진 속 상품 태그
→ 사용자 투표
→ 16강
→ 8강
→ 4강
→ 결승
→ PIXEL DESK CHAMPION

사진 속 상품을 클릭하면 해당 상품의 상세 페이지로 이동하도록 연결합니다.

## 기획 의도

고객이 구매한 상품을 실제 공간에서 사용하는 경험을
다시 새로운 콘텐츠로 활용하고자 합니다.

구매
→ 사용
→ 인증
→ 콘텐츠 생성
→ 다른 사용자의 상품 발견
→ 신규 구매

의 선순환 구조를 만드는 것이 목적입니다.

## 기대효과

- 사용자 생성 콘텐츠(UGC) 증가
- 상품의 실제 사용 사례 확보
- 서비스 체류시간 증가
- 재방문 증가
- 투표 및 토너먼트를 통한 참여 증가
- 데스크 사진에서 상품 상세로 구매 연결
- 커뮤니티 및 팬덤 형성

## 확장 방향

- 판교 BEST PIXEL DESK
- 분당 PIXEL DESK CUP
- 지역별 Desk Ranking
- 시즌별 Tournament
- 우승자 Profile Trophy 지급

# 4. Core Feature 02 — Compatibility Preview

## 기능 정의

사용자가 보유한 키보드 모델명 또는 품번을 입력하면
선택한 키캡이 해당 기기와 호환되는지 확인할 수 있도록 합니다.

예:

제조사: Keychron
모델명: K8
배열: ANSI

선택 상품: Hello Kitty Keycap

결과:
- Stem: 호환
- ESC: 호환
- Spacebar: 일부 규격 미지원
- 최종 결과: 일부 키만 장착 가능

## 미리착샷

호환 여부뿐 아니라,
선택한 키캡을 자신의 키보드에 장착했을 때의 예상 모습을 제공합니다.

예:

Keychron K8
→ Hello Kitty Keycap 선택
→ ESC 위치 선택
→ 적용 예상 이미지 표시

## 기획 의도

기존 구매 흐름:

상품 선택
→ 구매
→ 배송
→ 장착
→ 규격 불일치
→ 교환 또는 반품

PIXEL MART:

기기 입력
→ 호환성 확인
→ 미리착샷
→ 구매

구매 이후 발생하는 실패를 구매 전에 예방하는 것이 목적입니다.

## 기대효과

- 잘못된 규격 구매 감소
- 교환·반품률 감소
- CS 감소
- 재배송 비용 감소
- 구매 불안 감소
- 상품 신뢰도 향상
- 구매전환율 개선

# 5. Core Feature 03 — PIXEL LOCAL

## 기능 정의

지역과 취향을 기반으로
같은 관심사를 가진 사용자를 발견하고
거래·교환·커뮤니티 활동까지 연결하는 기능입니다.

당근이

지역
→ 사람
→ 거래
→ 커뮤니티

를 연결했다면,

PIXEL MART는

지역
+ 취향
+ 굿즈
+ Deskterior
+ 거래
+ 교환
+ 커뮤니티

를 연결합니다.

---

## 5.1 덕력지도

사용자의 취향 정보를 지역 단위로 익명 집계합니다.

예:

분당구

- 오로치마루 팬 8명
- 나루토 팬 31명
- 레트로게임 팬 46명
- 키캡 수집러 19명
- PIXEL DESK 사용자 23명

캐릭터를 클릭하면:

오로치마루
→ 지역 팬 수
→ 관련 상품
→ 지역 거래
→ 교환 상품
→ Deskterior
→ Community

로 연결합니다.

### 기획 의도

"내 주변에도 나와 같은 것을 좋아하는 사람이 있다."

라는 경험을 제공하여
상품이 아니라 취향을 중심으로 사용자를 연결합니다.

### 기대효과

- 지역 팬덤 형성
- 소속감 증가
- 커뮤니티 활성화
- 비구매 목적 방문 증가
- 지역별 취향 데이터 확보

---

## 5.2 PIXEL LOCAL × Deskterior

지역 정보와 데스크테리어 콘텐츠를 연결합니다.

예:

판교 인기 데스크

RETRO RPG DESK

사용 상품:
- Pixel Lamp
- Purple Keycap
- Dungeon Desk Mat

상품 상세에서는:

"이 상품을 사용한 판교 사용자 12명"

처럼 지역 기반 실제 사용 정보를 제공합니다.

### 기획 의도

상품 중심 커머스와 사람 중심 커뮤니티의 경계를 연결합니다.

### 기대효과

- 실제 사용 사례 기반 상품 탐색
- 상품 발견 증가
- 지역 기반 Social Proof 제공
- 커뮤니티에서 상품 페이지로 자연스러운 이동
- 상품 구매에서 커뮤니티 참여로 이동

---

## 5.3 Local Trade & Exchange

지역 사용자끼리 굿즈를 판매하거나 교환할 수 있도록 합니다.

특히 랜덤 굿즈의 경우
원하는 캐릭터가 나오지 않을 수 있으므로 HAVE / WANT 구조를 지원합니다.

예:

HAVE
- 카카시 키링

WANT
- 오로치마루 키링

MATCH!
1.2km 이내에 교환 가능한 사용자가 있습니다.

### 기획 의도

굿즈 구매 이후 발생하는 중복 상품,
교환 및 재판매 수요까지 서비스 안에서 해결합니다.

### 기대효과

- 중복 굿즈 활용
- 지역 거래 증가
- 사용자 간 연결 증가
- 커뮤니티 활성화
- C2C 서비스 확장 가능성

---

## 5.4 Local Wish Map

개인의 장바구니를 공개하지 않고,
지역별 관심 상품 데이터를 익명 집계합니다.

예:

판교에서 많이 원하는 상품

1. Hello Kitty Keycap — 38명
2. Orochimaru Figure — 27명
3. Pixel Slime Lamp — 21명

### 기획 의도

개인정보를 노출하지 않으면서
지역별 실제 상품 수요를 확인합니다.

### 기대효과

- 지역별 상품 수요 파악
- 공동구매 연결
- 지역 팝업 기획
- 재고 전략
- 상품 소싱 데이터 확보

# 6. Taste Search Strategy

PIXEL MART는 상품명 중심 검색보다
**취향 중심 탐색**을 강화하는 방향으로 설계합니다.

예:

- 보라색 RPG 책상
- 귀여운 핑크 키캡
- 분당 나루토 굿즈
- Keychron K8 호환 키캡
- 오로치마루 교환 가능

## 주요 필터

- 지역
- 캐릭터
- 작품
- 상품 종류
- 색상
- 분위기
- 가격
- 기기 모델
- 호환 여부
- 판매 / 교환
- 신상품
- 인기순

## 기획 의도

고객이 상품명을 정확히 몰라도
자신의 취향과 상황을 표현함으로써 원하는 상품을 찾을 수 있도록 합니다.

## 기대효과

- 상품 탐색 시간 감소
- 검색 실패 감소
- 상품 발견 증가
- 개인화 추천 기반 마련
- 검색 데이터를 활용한 상품 기획 가능

---

# 7. Gamification

서비스 참여를 게임 경험과 연결합니다.

예:

- NEW PLAYER
- PIXEL PLAYER
- RETRO MASTER
- BOSS CLEAR!

토너먼트 우승, 데스크 인증, 커뮤니티 활동 등에 따라
Profile Trophy 또는 Badge를 지급하는 방향을 검토합니다.

## 기획 의도

단순 할인 중심의 회원등급이 아니라
사용자가 활동 기록과 성취를 쌓고 싶게 만드는 것이 목적입니다.

## 기대효과

- 커뮤니티 참여 증가
- 재방문 증가
- 사용자 프로필 정체성 강화
- 팬덤 형성

---

# 8. Service Flywheel

PIXEL MART의 각 기능은 독립적인 기능이 아니라
다음의 하나의 사용자 경험으로 연결됩니다.

취향 검색
→ 상품 발견
→ 호환성 확인
→ 미리착샷
→ 구매
→ Deskterior 인증
→ Tournament
→ PIXEL LOCAL
→ 같은 취향 사용자 발견
→ 거래 / 교환 / 커뮤니티
→ 재방문
→ 새로운 상품 구매

---

# 9. MVP 및 확장 범위

이번 프로젝트에서는 실제 DB, 회원가입, 결제 시스템을 구현하지 않으므로
핵심 서비스의 UX를 Mock Data와 Prototype UI 중심으로 검증합니다.

| 기능 | 이번 프로젝트 | 향후 확장 |
| --- | --- | --- |
| 기본 쇼핑몰 | 실제 구현 | 운영 데이터 연결 |
| 상품 검색/필터 | Mock Data | 검색엔진/추천 |
| 호환성 | Mock 기기 데이터 | 실제 기기 DB |
| 미리착샷 | UI Prototype | 이미지 합성/3D |
| Deskterior | Sample Data | 사용자 업로드 |
| Tournament | UI Prototype | 실시간 투표 |
| 덕력지도 | Mock 지역 데이터 | 실제 지역 집계 |
| 지역 거래 | UI Prototype | 회원/채팅/DB |
| Wish Map | Mock 데이터 | 실제 관심 데이터 |
| Gamification | Mock Profile | 실제 활동 데이터 |

---

# 10. 장기 방향

PIXEL MART의 목표는 단순히 상품을 많이 판매하는 것이 아닙니다.

**굿즈를 사러 들어왔다가 취향 때문에 머무는 서비스**

를 지향합니다.

장기적으로는

취향
→ 사람
→ 지역
→ 콘텐츠
→ 거래
→ 커머스

가 하나의 플랫폼 안에서 순환하는
취향 기반 커뮤니티 커머스로 확장하는 것을 목표로 합니다.
