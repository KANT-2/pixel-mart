# PIXEL MART — 픽셀 아바타 운영정책

## 1. 만드는 방법

| 방법 | 사진 처리 | 결과 |
| --- | --- | --- |
| **픽셀 캔버스** | 사진을 쓰지 않음 — 브라우저에서 직접 그림 | 그린 PNG만 서버에 저장 |
| **AI 픽셀 아바타** (선택) | 사용자가 **동의한 경우에만** 사진을 **Cloudflare Workers AI**(FLUX.2 klein)로 한 번 전송 | 생성된 픽셀아트를 브라우저에서 격자로 정리한 뒤, 사용자가 고르면 PNG만 저장 |

- AI 아바타는 사진 속 **사람·동물·캐릭터**를 인식해 자세·옷차림·비율·색을 살린 픽셀아트 스프라이트로 다시 그립니다.
- AI 결과는 픽셀 캔버스에서 이어서 다듬을 수 있습니다.

## 2. 사진 처리 원칙 (AI 픽셀 아바타)

1. **동의 후에만 전송** — "사진이 Cloudflare Workers AI로 전송된다"는 안내에 동의(체크)해야 버튼이 활성화됩니다. 서버도 동의값이 없으면 거절합니다.
2. **저장하지 않음** — 원본 사진과 생성 원본 이미지는 요청을 처리하는 동안 메모리에서만 쓰고 DB·파일·로그에 남기지 않습니다. 서버에 저장되는 것은 사용자가 고른 **최종 픽셀 PNG(50KB 이하)** 뿐입니다.
3. **브라우저에서 먼저 줄임** — 전송 전 긴 변 504px 이하 JPEG로 줄여 보냅니다 (모델 입력 512px 미만 제한, EXIF 위치 정보 등은 다시 그리면서 제거).
4. **외부 서비스 정책** — 전송된 사진은 **Cloudflare Workers AI**(무료 일일 할당) 약관과 모델 `@cf/black-forest-labs/flux-2-klein-4b` 제공사 Black Forest Labs 약관에 따라 처리됩니다. 원하지 않으면 픽셀 캔버스를 이용하세요.
   - 무료 할당을 다 쓰면 그날은 AI 만들기를 쓸 수 없다고 안내합니다.
   - 출력 안전 필터가 오탐하면(같은 사진도 시드에 따라 걸림) 서버가 다른 시드로 최대 5번까지 다시 시도하고, 그래도 안 되면 사진을 브라우저에서 바로 픽셀로 바꾸는 방법을 안내합니다.
   - 동의 문구의 제공자 이름은 서버 설정(`GET /api/avatars/ai`)을 그대로 보여 줍니다.
5. **사용량 제한** — 사용자당 1시간에 정해진 횟수(기본 10회)까지 만들 수 있습니다.
6. **키 관리** — Cloudflare Account ID·API 토큰은 `backend/.env`의 `CLOUDFLARE_ACCOUNT_ID`·`CLOUDFLARE_API_TOKEN`에만 두고 브라우저·저장소·로그에 노출하지 않습니다. 키가 없으면 AI 만들기만 꺼지고 캔버스는 그대로 쓸 수 있습니다.

## 3. 부적절한 아바타 제재

아바타는 메인 무대·헤더·덕력지도(동의 시) 등 다른 사용자에게 보일 수 있습니다. 다음에 해당하는 아바타는 **경고 없이 삭제되거나 이용이 제한될 수 있습니다.**

- 선정적·폭력적·혐오 표현
- 타인을 사칭하거나 동의 없이 특정인을 묘사한 이미지
- 욕설·연락처·광고 등 텍스트가 들어간 이미지
- 저작권·상표를 침해하는 이미지 (공식 로고·캐릭터 원본 그대로 옮기기 등)

AI 생성 시 제공자의 안전 필터가 차단하면 아바타를 만들 수 없다는 안내를 보여 줍니다.
