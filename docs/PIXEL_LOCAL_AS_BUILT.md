## 0. PIXEL LOCAL이 하려는 것

> **"우리 동네에 나와 같은 덕후가 있다는 걸 보여 주고, 그 이웃과 굿즈를 안전하게 주고받게 하는 곳"**

| 단계 | 의미 | 구현된 화면 |
| --- | --- | --- |
| **발견** | 우리 동네 취향 분포를 익명으로 본다 | 덕력지도, 위시맵의 "이 동네 인기 찜" |
| **연결** | 같은 취향 이웃과 주고받는다 | 거래·교환(HAVE/WISH/SELL, 매칭), 이웃 선물 |
| **신뢰** | 주고받은 활동이 쌓여 믿을 수 있는 이웃이 된다 | 활동 점수 → 하트·레벨·코인, 뱃지 19종, 이웃 카드, 알림 |

지키는 원칙: **위치 추적 안 함**(좌표 미저장) · **개인 노출 안 함**(모든 공개는 본인 동의, 기본 OFF) · **숫자는 집계로만**(사용자 목록·금액 비공개)

## 2. 내 동네·취향 설정

| 항목 | 현재 동작 |
| --- | --- |
| 동네 | "시 / 구 / 동·생활권"을 직접 선택. "내 위치로 찾기"는 누를 때만 위치 권한 요청 → 15km 안의 가장 가까운 생활권을 골라 줌. **좌표는 서버로 보내지 않고 저장하지 않음** |
| 취향 | 최대 20개 선택. 현재 취향 목록은 **작품 53개**(애니 25 · 게임 25 · 장르 태그 3: 레트로 RPG · 픽셀 게임 · 던전 크롤러), 모두 "작품" 한 축 |
| 저장 | "저장"을 눌러야 반영 (지역을 미리 골라 들어와도 자동 저장하지 않음) |
| 점수 | 동네 + 취향 1개 이상을 처음 저장하면 활동 점수 +5 (평생 1회) |

## 3. 덕력지도 (발견)

### 화면

- 제목 "덕력지도" · "우리 동네 이웃들이 좋아하는 작품을 지도에서 찾아보세요."
- 취향 칩: "전체 · 동네 인기 취향" + 내 취향(없으면 지도 1위 취향들) + "⌕ 취향 찾기 · N"
- 동네 검색 "동네 검색 (예: 판교)" · "내 위치로 보기"(모바일은 ◎)
- 지도: 시를 누르면 구로, 구를 누르면 생활권으로 들어감. 확대 "+ / − / ⟲", 끌어서 이동
- 이름표 "{지역} · {1위 취향} {N}명", 0명이면 "아직 없음"
- 색 범례 "적음 · 보통 · 많음" (보이는 지도의 최댓값 대비 3단계, 0명은 흐린 색)
- 샘플 데이터 배지는 **화면에서 제거됨** (PR #149, 팀 결정) — 서버는 `isSample`을 계속 내보냄

### 규칙

| 항목 | 기준 |
| --- | --- |
| 집계 대상 | "덕력지도 집계 참여"를 켠 사용자 (테스트 계정 제외) |
| 집계 단위 | 지역 × 취향별 **사람 수**. 하위 지역은 상위 지역에 합산 |
| 최소 인원 | **제한 없음** — 1명부터 그대로 표시 (2026-10-12 팀 결정, PR #136) |
| 샘플 | 실제 데이터가 없는 칸을 샘플로 채움(Cold Start용). 서버는 `isSample`을 주지만 화면에는 표시하지 않음 |
| 기간 | 전체 / 30일 / 90일 (취향을 고른 시점 기준) |

### 지역을 눌렀을 때 (오른쪽 패널, 모바일은 아래에서 올라오는 시트)

| 표시 | 내용 |
| --- | --- |
| 인원 | "{N}명의 {취향} 팬이 있어요" |
| "이 동네 인기 취향" | 상위 3개와 인원 |
| "구매 순위 TOP 10" | 아바타 표시 동의자를 **구매 금액(취소 제외) 순**으로 10명(같은 금액은 하루 고정 순서라 지도 캐릭터 순서와 같음, 샘플이 섞이면 "샘플 포함"). **금액 비공개**, 닉네임은 공개 동의자만(아니면 "이웃 플레이어") |
| 버튼 | "이 동네 교환글 보기" · "{취향} 관련 상품" · "여기를 내 동네로" |

### 지도 캐릭터와 이웃 카드

| 항목 | 기준 |
| --- | --- |
| 지도 캐릭터 | 지역당 최대 10명. 아바타 표시 동의자가 있으면 실제 아바타(구매 금액 순), 없으면 서버가 그린 **샘플 캐릭터**, 그것도 없으면 기본 슬라임 |
| 캐릭터 위치 | 장식용 무작위 배치 (실제 위치와 무관) |
| 이웃 카드 | 카드 공개 동의자만: 하트 아이콘 + "×N" · "LV.{1~10} {레벨 이름}" · "이 동네 구매 {n}위 · 금액 비공개"(샘플 캐릭터는 순위 대신 "샘플" 표시) · 교환·거래 횟수(예: 50회+) · "취향"(취향 공개 시) · 대표 뱃지 + 받은 수 |
| 카드에서 이동 | 닉네임 공개 + 진행 중 WISH가 있으면 "WANT {n}개 보기 · 선물하기" → 위시맵 |
| 내 카드 | "내 활동 점수 {n}점 · 교환·거래 {n}건", 다음 하트까지 진행 바 — **정확한 점수는 본인만** |
| 내보내지 않는 것 | 사용자 id · 구매 금액 · 정확한 점수 · 위치 · 프로필 링크 |

## 4. 위시맵 (발견 + 연결)

| 항목 | 현재 동작 |
| --- | --- |
| 지도의 선물 상자 | 그 동네에서 진행 중인 **WISH 글(구하는 물건) 개수** — 아이콘이 하트에서 **픽셀 선물 상자**로 바뀜 (PR #206). 샘플·데모 글 포함 |
| 검색 | "동네 \| 닉네임 \| 아이템" |
| 패널 | "WISH {N}개" + 글 목록(닉네임 공개자만 닉네임, 그 외 "이웃 플레이어") |
| "선물하기" | 내 글 아님 · 샘플 아님 · 진행 중 · PIXEL MART 상품이 연결된 글일 때만 활성 |
| "이 동네 인기 찜" | 상품 **찜(♡) 집계**. 집계 참여 동의자 기준, 상위 3개. 실제 찜이 없으면 샘플 |
| 글쓰기 | "내 WISH 올리기" → 거래 글쓰기(WISH) |

> "WISH {N}개"(선물 상자, 구하는 글 수)와 "이 동네 인기 찜"(하트, 상품 찜 수)은 **서로 다른 데이터**이며, 아이콘도 구분됩니다.

## 5. 거래·교환 (연결)

### 글 종류와 입력

| 종류 | 화면 | 의미 |
| --- | --- | --- |
| HAVE | "가진 물건" / "교환 가능" | 바꿀 수 있는 물건 |
| WISH | "위시" | 구하는 물건 |
| SELL | "판매" | 파는 물건 |

| 칸 | 기준 |
| --- | --- |
| 물건명 | 1~60자 |
| 물건 상태 | 새 상품 / 거의 새 상품 / 사용감 있음 — HAVE·SELL 필수 |
| 희망 가격 | 0~10,000,000원, 선택 |
| 거래 방식 | 직접 교환·거래 / 택배 / 모두 |
| 내용 | 최대 1,000자 |
| 상품·취향 연결 | 각 1개, 선택 |
| 지역 | 요청값이 아니라 **내 동네 설정에서 자동** (동네 미설정 시 작성 불가) |

### 안전 규칙

| 규칙 | 기준 |
| --- | --- |
| 연락처 금지 | 휴대폰 번호, 이메일, 카카오 오픈채팅·"카톡 아이디", "○동 ○호"·"○번지" 패턴이 있으면 등록 거부 (화면: "연락처는 적을 수 없어요") |
| 중복 금지 | 같은 종류로 진행 중인 글 중 같은 상품·같은 물건명이 있으면 거부 |
| 작성자 노출 | 닉네임 공개 동의자만 닉네임·아바타, 샘플 글은 항상 익명 |
| 상태 | 진행 중 → "거래 완료" 또는 "숨기기" (본인 글만, 다시 진행 중으로 되돌리기 없음) |

### 게시판 · 매칭

- 게시판: 진행 중 글만, 종류 "ALL / HAVE / SELL", 닉네임·아이템 검색, 지역(하위 포함) 필터, 최신순
- "내 글·매칭": 내 진행 중 WISH와 이웃의 HAVE·SELL을 비교 — 같은 상품 → 같은 취향 → 같은 물건명 순으로 판정, **같은 생활권·같은 구**만, 서로 원하는 교환("서로 원하는 교환")을 먼저
- **교환 신청 (PR #146)**: 게시판 카드·교환 창의 "⇄ 교환 신청" → 작성자의 "교환 신청함"(받은/보낸 탭)에서 "수락"/"거절", 신청자는 "신청 취소"
  - 수락하면 두 글이 모두 거래 완료, 같은 글의 다른 대기 신청은 자동 거절, **양쪽 모두 +20점**
  - 사용자 메뉴 "교환 신청함", 알림으로 바로 이동

## 6. 이웃 선물 (연결 + 매출)

| 단계 | 현재 동작 |
| --- | --- |
| 대상 | 이웃의 **WISH 글 중 PIXEL MART 상품이 연결된 글**만. 내 글·샘플·완료·숨김 글은 불가 |
| 보내기 | 수량 1~9개, 메시지 최대 100자(연락처 금지) → "선물 결제하기" (**데모 결제**, 결제수단 입력 없음) |
| 받기 | 받는 사람이 선물함에서 "받기" → 이름·주소 직접 입력 → **받는 사람의 주문 생성**, 배송 흐름 시작 |
| 거절 | "거절하기" → 보낸 쪽에 "거절 · 환불(데모)" 표시 |
| 익명 | 서로를 "이웃 플레이어"로만 봄. 주소·계정은 상대에게 비공개 |
| 헤더 | 선물 아이콘에 받기 대기 수 배지 |
| 데모 이웃 | 시연용 계정 8명(`seed_demo`), "데모 이웃" 표시, 집계에서 제외 |

## 7. 활동 점수 · 하트 · 코인 (신뢰)

| 첫 WISH 글 등록 | +10 | 평생 1회 |

### 표시

| 요소 | 의미 | 기준 | 누가 보나 |
| --- | --- | --- | --- |
| ♥ 하트 0~99 | 동네 커뮤니티 참여도 | 30 · 65 · 90점, 이후 30점마다 +1. 화면은 하트 아이콘 + "×N" | 카드 공개 시 이웃에게 |
| 레벨 LV.1~10 | 하트보다 천천히 오르는 단계 | 하트 1·4·9·16…개마다 1씩, 이름: 새내기 → 동네 → 친한 → 단골 이웃 | 카드 공개 시 |
| 🪙 코인 | 완료한 거래·교환 수 | 이웃에게는 구간만 "교환 1·5·10회+" | 카드 공개 시 구간만 |
| 정확한 점수·건수 | | | **본인만** (내 캐릭터 카드) |
| 🏅 뱃지 19종 | 처음 해낸 일·누적 업적 | 주문·리뷰·활동 점수·거래·선물 기록으로 계산 (PR #204) — 첫 접속·동네 등록·지도 데뷔·첫 장착·첫 WANT·첫 거래·리뷰어·컬렉터·동네 산타·소원 성취·유니크 헌터·단골 이웃·교환 장인 Ⅰ~Ⅲ·하트 수집가 Ⅰ~Ⅲ·동네 큰손 | 마이페이지 도감, 이웃 카드 대표 뱃지 |
